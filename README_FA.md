# NEXUS AI TRADER - نسخه 0.2

پنل فارسی آزمایشی برای تحلیل بازار، بک‌تست پایه، بررسی سیگنال نمونه، جست‌وجوی DEX و دفترچه یادگیری.

## اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

**محدودیت‌ها:** معاملات واقعی و اتصال حساب‌ها پیاده‌سازی نشده‌اند. سیگنال‌ها آموزشی‌اند. بک‌تست ساده است و تضمین سود ندارد. ابزار DEX امنیت قرارداد را بررسی نمی‌کند. یادگیری خودکار از YouTube و Telegram هنوز وجود ندارد. هیچ seed phrase یا private key وارد نکنید.


## اجرای نسخه روی گوشی بدون خرید سرور

راهنمای استقرار آزمایشی از طریق Streamlit Community Cloud: [راهنمای فارسی](docs/PHONE_CLOUD_QUICKSTART_FA.md). این روش میزبانی ابری رایگان/دارای محدودیت است و اجرای دائمی یا ذخیره‌سازی پایدار را تضمین نمی‌کند.
