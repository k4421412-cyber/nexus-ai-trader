# NEXUS AI TRADER

MVP آزمایشی برای تحلیل داده بازار، بک‌تست ساده و جست‌وجوی جفت‌ارزهای DEX.

## اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

این نسخه معامله واقعی، اتصال کیف پول/صرافی یا یادگیری خودکار از YouTube و Telegram ندارد. از کلید خصوصی و عبارت بازیابی استفاده نکنید.

## زبان‌ها و پشتیبانی جهانی

پشتیبانی چندزبانه و آماده‌سازی رابط برای زبان‌های گوناگون، از جمله زبان‌های راست‌به‌چپ، از الزامات پروژه است. جزئیات معماری، ترجمه‌ها، قالب‌بندی محلی و معیارهای پذیرش در [سند پشتیبانی چندزبانه](docs/INTERNATIONALIZATION.md) آمده است. این قابلیت باید بدون تغییر در محاسبات و منطق معاملاتی پیاده‌سازی شود.

## سرمایه‌گذاری مشارکتی و تقسیم سود

قرار است بخشی برای سرمایه‌گذاران و مدیران استراتژی اضافه شود تا تخصیص سرمایه و تقسیم سود خالص بر اساس توافق شفاف ثبت شود. در نسخه MVP این قابلیت فقط با سرمایه مجازی و معاملات شبیه‌سازی‌شده فعال خواهد بود؛ دریافت یا نگهداری پول واقعی و اجرای معاملات با سرمایه دیگران تا بررسی حقوقی، امنیتی و تأیید جداگانه غیرفعال می‌ماند. جزئیات در [سند سرمایه‌گذاری مشارکتی](docs/SOCIAL_INVESTMENT.md) آمده است.
