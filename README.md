# NEXUS AI TRADER

MVP آزمایشی برای تحلیل داده بازار، بک‌تست ساده و جست‌وجوی جفت‌ارزهای DEX.

## اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

این نسخه معامله واقعی، اتصال کیف پول/صرافی یا یادگیری خودکار از YouTube و Telegram ندارد. از کلید خصوصی و عبارت بازیابی استفاده نکنید.
