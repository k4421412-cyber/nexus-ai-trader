# راه‌اندازی NEXUS روی گوشی بدون خرید سرور

## گزینه پیشنهادی: Streamlit Community Cloud

این روش برنامه را روی زیرساخت میزبانی‌شده Community Cloud اجرا می‌کند؛ گوشی فقط با مرورگر به پنل وصل می‌شود. بنابراین برنامه مستقیماً روی سخت‌افزار گوشی اجرا نمی‌شود و خرید VPS لازم نیست.

### پیش‌نیازها
- حساب GitHub با دسترسی مدیریتی به مخزن NEXUS
- حساب Streamlit Community Cloud
- اینترنت برای باز کردن پنل

### مراحل راه‌اندازی
1. وارد https://share.streamlit.io/ شوید و با GitHub ثبت‌نام/ورود کنید.
2. گزینه **Create app** را بزنید.
3. این مقادیر را وارد کنید:
   - Repository: `k4421412-cyber/nexus-ai-trader`
   - Branch: `main`
   - Main file path: `app.py`
4. در تنظیمات پیشرفته، Python 3.11 را انتخاب کنید.
5. Deploy را بزنید و صبر کنید تا ساخت برنامه تمام شود.
6. از URL ساخته‌شده با مرورگر گوشی وارد NEXUS شوید؛ می‌توانید آن را به صفحه اصلی گوشی اضافه کنید.

## حریم خصوصی و محدودیت‌های مهم

- مخزن GitHub فعلاً عمومی است. برنامه‌ای که از مخزن عمومی Deploy شود ممکن است به‌صورت عمومی قابل مشاهده باشد. پس از استقرار، در App settings بخش Sharing را بررسی کنید و اگر گزینه آن در دسترس بود، نمایش را به افراد مجاز محدود کنید. هیچ اطلاعات محرمانه یا کلید API را در کد قرار ندهید.
- نسخه فعلی فقط برای Paper Trading و داده‌های عمومی بازار است. کلید خصوصی، عبارت بازیابی، کلید برداشت صرافی یا پول واقعی وارد نکنید.
- موجودی و وضعیت آزمایشی داخل نشست ممکن است با پایان نشست یا راه‌اندازی مجدد برنامه از بین برود. تا وقتی ذخیره‌سازی دائمی و بازیابی روی این میزبان جداگانه آزمایش نشده، این فضا را دفترکل دائمی تلقی نکنید.
- این سرویس جایگزین سرور اختصاصی با تضمین اجرای شبانه‌روزی نیست؛ ممکن است برنامه متوقف یا خوابانده شود و محدودیت منابع/استفاده داشته باشد.
- به‌دلیل عمومی بودن مخزن، پیش از عمومی کردن اپ باید کد و داده‌های قابل مشاهده را بازبینی کنیم.
